# Activity Log

Activity Logs help you monitor important events and changes within your organization. They provide an audit trail for organization management, authentication events, and store credential operations.

The following activity logs are available:

* [Organization Activity Log](/account/my-organization/activity-log/organization-activity)
* [Auth Activity Log](/account/my-organization/activity-log/auth-activity-log)
* [Credential Activity Log](/account/my-organization/activity-log/credential-activity-log)
